Distributed version of a board game

Hardware component in VHDL

Priority-ordered task list in external memory

  • Logic circuit that manages a priority-ordered task list in external memory, with four operations and a handshake protocol, implemented as a 23-state Moore machine.
  • Synthesized on an Artix-7 FPGA with Vivado: 112 LUTs, 71 flip-flops, no inferred latches, and the 20 ns clock constraint met with a wide margin.
  • Verified with behavioural and post-synthesis simulation, plus my own extended 11-step testbench for edge cases the course testbench did not cover.
  • VHDL
  • Xilinx Vivado
  • Artix-7 FPGA
  • FSM design
